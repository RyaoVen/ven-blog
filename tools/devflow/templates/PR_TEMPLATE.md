# PR 模板（/devflow-pr 渲染用）

> 渲染后先给用户确认，再调用 gitcode.sh pr-create；随后 pr-link 关联 Issue。

```markdown
## 背景

{{一两句话说明为什么做。}}

关联 Issue: #{issue}

## 改动摘要

{{按层列出关键改动；对应 PLAN-{issue}.md 的实现步骤，逐项勾选}}

- [ ] {{步骤 1（对应 PLAN §4）}}
- [ ] {{步骤 2}}

## 契约与文档

- [ ] 接口/表结构无变更，或 docs/02、docs/03 已同步（列出生效的契约变更）

## 自测记录

| 检查 | 结果 |
|---|---|
| 后端编译/测试（mvn test） | {{通过 / N/A}} |
| 前端构建（pnpm build） | {{通过 / N/A}} |
| 手工验证 | {{关键操作与结果，附截图}} |

## 评审关注点

{{主动提示评审人重点看哪里：事务边界、锁顺序、错误码、边界条件…}}

## 回滚方案

{{squash 单提交，revert 即可 / 其他说明}}
```
